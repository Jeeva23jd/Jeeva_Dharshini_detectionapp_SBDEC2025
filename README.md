# Jeeva_Dharshini_detectionapp_SBDEC2025
🏛️ HeritageLens AI
Intelligent Detection of Heritage Sites and Archaeological Structures

HeritageLens AI is a sophisticated deep-learning powered application designed to detect, classify, and analyze heritage sites, archaeological structures, and natural landscapes from both images and videos.
Built using YOLO, Streamlit, and advanced computer vision techniques, the application supports automated analysis, visualization, and reporting for heritage research and documentation.
